# llm-buddy
llm-buddy is an tool that watches your recent edits and asks an
LLM to review them.  When it finds something worth pointing out, it adds a
short inline note.

The goal is lightweight feedback while you work: typos, logic mistakes,
questionable edits, or prose issues that a normal compiler, linter, or spell
checker may not catch.  It also can make fixes as it finds smaller problems, if
configured to do so.

* `emacs` contains the the original emacs implementation
* `code` contains the vs code extension
* `studio` will (hopefully) contain the visual studio extension

This is heavily inspired/fork of the original [llm-buddy project for emacs](https://github.com/ahyatt/llm-buddy).
